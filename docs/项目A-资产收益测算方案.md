# 项目 A：车辆资产收益测算方案

## 决策目标

建立从车辆成本到租金定价的可复现分析链路，支持以下决策：

- 识别高成本或情景利润为负的 Segment 与城市。
- 评估维保、折旧、保险和停车成本的结构性差异。
- 量化里程、动力、车型和配置对日租金的影响。
- 比较规则定价与回归模型的样本外误差。

## 分析架构

```text
原始公开数据
  ├─ Zenodo 车辆与维保发票
  └─ Getaround 定价与租赁活动
          ↓
字段清洗、类型校验、映射与血缘记录
          ↓
SQLite 资产层 / 成本层 / 定价层
          ↓
TCO 与情景盈利 → 定价因子 → Ridge 定价模型
          ↓
管理摘要与运营动作
```

## 数据表

| 表 | 粒度 | 作用 |
|---|---|---|
| `vehicle_asset` | 一车一行 | 车辆属性主数据 |
| `cost_monthly` | 一车一月一行 | 月度成本明细 |
| `city_factor` | 一城市一行 | 城市成本与规模因子 |
| `getaround_pricing` | 一挂牌车辆一行 | 租金与定价特征 |
| `getaround_rental_activity` | 一笔活动一行 | 租赁活动与周转信息 |
| `segment_rent_benchmark` | 一 Segment 一行 | 情景收入基准 |
| `data_source` | 一来源一行 | 数据血缘 |

## 核心口径

| 指标 | 计算方式 |
|---|---|
| 月折旧 | 采购价 × (1 − 残值率) / 折旧月数 |
| 月度 TCO | 折旧 + 保险 + P99 封顶维保 + 停车 |
| 情景月收入 | Segment 月租金基准 × 利用率参数 |
| 情景月利润 | 情景月收入 − 月度 TCO |
| 利润率 | 情景月利润 / 情景月收入 |

## 质量控制

- 主键、重复记录、日期范围和金额字段在入库前校验。
- 原始维保金额与 P99 封顶经营口径同时保留。
- 跨数据集仅按 Segment 建立基准映射，不进行车辆级拼接。
- 所有非观测参数集中维护在 `project_a/src/config.py`。

## 交付物

| 阶段 | 交付物 |
|---|---|
| 数据层 | SQLite 数据库、表结构与血缘记录 |
| 成本与盈利 | 单车月度 TCO、Segment/城市汇总、成本结构图 |
| 定价因子 | 相关矩阵、类别因子对比、配置溢价 |
| 定价模型 | Baseline/Ridge 指标、测试集预测、系数表 |
| 管理输出 | 核心发现、运营动作和数据限制 |

## 使用边界

公开数据来自不同市场且缺少统一车辆标识；采购价、固定成本和利用率属于情景参数。因此盈利结果用于比较和敏感性分析，不作为企业财务账面结果。
