# 车辆资产分层与退网预警设计

## 决策目标

在车队规模较大、人工无法逐车盘点的条件下，通过资产画像和风险排序确定优先核查范围，并为调拨、维保和处置提供统一的数据入口。

## 时间设计

```text
观察期 2021-01 至 2022-06：构造 RFM 与趋势特征
预测期 2022-07 至 2023-02：以无维保活动定义退网代理标签
```

项目 A 的 `disposal` 表由末次维保时间派生，与 Recency 同源，因此不直接作为训练标签。时间窗口分离可避免定义性标签泄露。

## 特征口径

| 维度 | 定义 | 解释 |
|---|---|---|
| Recency | 观察期末距末次活跃月的月数 | 资产沉默程度 |
| Frequency | 观察期内活跃月份数 | 持续运营频率 |
| Monetary | 观察期累计维保金额 | 资产投入强度 |
| 趋势特征 | 活跃、金额和间隔的近期变化 | 捕捉状态变化 |

## 分层方法

- 规则分层：将 RFM 分位分数映射为可执行的资产标签。
- K-Means：识别数据中的自然分组，检验规则分层的方向稳定性。
- 风险模型：比较 Logistic、随机森林和梯度提升模型，对车辆进行概率排序。

## 运营输出

| 输出 | 用途 |
|---|---|
| 车辆级资产标签 | 车队结构盘点与差异化策略 |
| 聚类画像 | 验证分层方向和识别非线性组合 |
| 风险分位 | 确定月度优先核查范围 |
| 十分位 Lift | 评估有限资源下的筛选效率 |
| 特征重要性 | 定位数据瓶颈和补充字段 |

## 控制要求

- 风险评分仅用于排序，不触发自动处置。
- 每次核查需记录真实状态、动作、成本和结果，以支持后续效果评估。
- 代理标签需在获得合同或处置状态后重新校准。

## 局限

1. Monetary 为维保投入代理，不等同于收入或资产价值。
2. 无维保活动可能包含长期闲置、外部维修或数据缺失。
3. 当前字段不足以覆盖合同、里程、故障和残值风险。
